= Gestisci le autorizzazioni dell'agente della console per le distribuzioni di Google Cloud
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Occasionalmente, NetApp aggiorna le autorizzazioni richieste per l'account di servizio utilizzato per l'agente della console quando viene distribuito in Google Cloud.

link:reference-permissions-gcp.html["Verificare l'elenco delle autorizzazioni Google richieste"].

Utilizza Google Cloud Console per aggiornare il ruolo IAM assegnato all'account di servizio in modo che corrisponda al nuovo set di autorizzazioni.

link:https://docs.cloud.google.com/iam/docs/creating-custom-roles?hl=en#edit-role["Documentazione di Google Cloud: modifica un ruolo personalizzato"]
