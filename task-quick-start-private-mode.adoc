= Flusso di lavoro introduttivo per NetApp Console in modalità privata
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
È possibile installare NetApp Console in locale o in un ambiente cloud sicuro. La modalità privata viene in genere utilizzata con ambienti locali privi di connessione Internet e con regioni cloud sicure, che includono https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] e https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"] link:task-prepare-private-mode.html["Prepararsi per la distribuzione"]
[role="quick-margin-list"]
. Preparare un host Linux dedicato che soddisfi i requisiti di CPU, RAM, spazio su disco, strumento di orchestrazione dei container e altro ancora.
. Configura il networking che fornisce accesso alle reti di destinazione.
. Per le distribuzioni cloud, configura le autorizzazioni nel tuo cloud provider in modo da poterle associare all'agente Console dopo aver installato il software.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"] link:task-install-private-mode.html["Distribuisci l'agente della console"]
[role="quick-margin-list"]
. Installa l'agente Console sul tuo host Linux.
. Configura NetApp Console aprendo un browser web e inserendo l'indirizzo IP dell'host Linux.
. Per le distribuzioni cloud, fornisci alla NetApp Console le autorizzazioni che hai configurato in precedenza.




== Funzionalità e servizi supportati per NetApp Console in modalità privata

La tabella seguente elenca le funzionalità di gestione dello storage, i servizi dati e le funzionalità amministrative disponibili in NetApp Console quando la si installa in modalità privata. Le funzionalità variano a seconda che la NetApp Console venga installata nel cloud o presso la propria sede.
