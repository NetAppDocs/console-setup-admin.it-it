= Ruoli di accesso di Cloud Volumes ONTAP nella NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puoi assegnare i seguenti ruoli agli utenti per consentire loro l'accesso a Cloud Volumes ONTAP all'interno della NetApp Console.


NOTE: I ruoli di accesso per Cloud Volumes ONTAP sono disponibili quando esegui un agente Console versione 4.9.0 o successiva.

* *Cloud Volumes ONTAP admin*: Fornisce accesso completo a tutte le operazioni di Cloud Volumes ONTAP.
* *Cloud Volumes ONTAP operator*: Esegue importanti operazioni di storage, come la scoperta e la gestione dei sistemi Cloud Volumes ONTAP, inclusa l'aggiunta di volumi, aggregati, snapshot e repliche, la modifica di alcune configurazioni e l'aggiornamento delle versioni di Cloud Volumes ONTAP.
* *Cloud Volumes ONTAP viewer*: Fornisce accesso in sola lettura alle informazioni di Cloud Volumes ONTAP. Questo ruolo non può eseguire operazioni attive. Alcune schede e schermate contenenti informazioni di configurazione potrebbero non essere disponibili per i viewer.


Per i dettagli su tutti i ruoli di accesso alla NetApp Console, vedere link:reference-iam-predefined-roles.html["ruoli di accesso"].



[[how-role-changes-take-effect]]
== Come entrano in vigore le modifiche in base al ruolo

Attendi fino a un'ora perché le nuove o aggiornate assegnazioni di ruolo abbiano effetto. Cloud Volumes ONTAP aggiorna le assegnazioni di ruolo ogni ora.
