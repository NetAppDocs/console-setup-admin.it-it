.Prima di iniziare
* È richiesto un account IdP con privilegi amministrativi.  Coordinati con l'amministratore dell'IdP per completare i passaggi.
* Identifica il dominio che desideri utilizzare per la federazione. Puoi utilizzare il tuo dominio di posta elettronica o un altro dominio di tua proprietà. Se desideri utilizzare un dominio diverso dal tuo dominio di posta elettronica, devi prima verificare il dominio nella Console. Per istruzioni, consulta link:task-federation-verify-domain.html["Verifica il tuo dominio nella NetApp Console"].
