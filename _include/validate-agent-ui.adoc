== Risoluzione dei problemi relativi a una distribuzione non riuscita dell'agente Console

Utilizza il report di distribuzione per individuare cosa ha bloccato la distribuzione dell'agente Console, quindi riprova.

La Console fornisce un report solo se è stata selezionata la check box *Validate agent configuration*. Se la distribuzione riesce, non viene generato alcun report.

.Passi
. Nella finestra di dialogo *Distribuzione agente non riuscita*, seleziona *Scarica report*.
+
Console scarica un file PDF contenente il report di convalida.

. Esamina il report e risolvi i problemi che elenca.
. Nella finestra di dialogo, seleziona *Start over* e quindi completa di nuovo la distribuzione.
+
Per riprovare, devi ricominciare l'intero processo da capo.
